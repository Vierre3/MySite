# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — start dev server at localhost:3000
- `npm run generate` — static site generation (prerendered HTML for GitHub Pages)
- `npm run preview` — preview the generated static site locally
- No test framework is configured.

## Deployment

Pushes to `main` trigger GitHub Actions → `nuxt generate` → GitHub Pages at vierre3.dev. The build sets `NUXT_APP_BASE_URL` and `NUXT_PUBLIC_SITE_URL` from the workflow.

## Architecture

**Nuxt 4 + Vue 3 + Tailwind CSS** portfolio site, statically generated with SSR prerendering.

### Key architectural decision: all sections live in app.vue, not in pages

All section components (Hero, About, Skills, Experience, Projects, Contact) are rendered directly in `app/app.vue`, outside `<NuxtPage>`. The `app/pages/index.vue` is an empty `<div />` shell that exists only to satisfy Nuxt's route requirements.

**Why:** `@nuxtjs/i18n` uses a `prefix` strategy with `/en` and `/fr` routes. Switching locale triggers a route change, which would remount everything inside `<NuxtPage>`. By placing sections in `app.vue`, they never remount on locale switch — `$t()` reactively updates text in place without losing component state (scroll position, animation state, filter selections).

### i18n routing

- Strategy: `prefix` — all routes are `/en/...` or `/fr/...`, no unprefixed routes
- `index.html` and `404.html` are generated by a Nitro build hook (`nuxt.config.ts`) as locale-redirect pages (check localStorage for preferred locale)
- Locale preference is persisted to `localStorage` in `app.vue`
- Locale switch uses `navigateTo()` via `useSwitchLocalePath()`; sections don't remount since they live in `app.vue`

### Theme system

- CSS custom properties defined in `app.vue` under `.dark` / `.light` classes on `<html>`
- `useTheme()` composable manages the class toggle; defers `localStorage` read to `onNuxtReady()` to avoid hydration mismatch (the inline `<head>` script handles visual preview before hydration)
- An inline `<head>` script (in `nuxt.config.ts`) applies theme + scroll position before hydration to prevent flash
- Theme-level `--shadow-color` variable controls navbar shadow visibility per theme (blue-tinted for dark mode since black-on-black is invisible)
- Global `*` selector applies `transition: color 300ms, background-color 300ms, border-color 300ms, fill 300ms, stroke 300ms` for smooth theme switching
- `theme-color` meta tag updates reactively based on current theme

### Pre-hydration strategy

A blocking inline script in `<head>` (configured in `nuxt.config.ts` `app.head.script`) runs before Vue hydrates to:
1. Add `html.loading` class (removed by `app.vue` on mount)
2. Apply saved theme from localStorage (replace `dark` with `light` if needed)
3. Read scroll position from sessionStorage and restore it via `requestAnimationFrame`
4. Add `html.scrolled` class so navbar shows its backdrop immediately

The `html.loading.scrolled .scroll-reveal` CSS rule prevents opacity:0 flash only during pre-hydration. Once Vue mounts and removes `loading`, scroll-reveal animations work normally via IntersectionObserver.

The `useScrollRestore` composable coordinates with this: it sets `isRestoring = true` during restore, and `app.vue` applies `.skip-animations` to suppress entrance animations during restore.

### Router

`app/router.options.ts` returns `scrollBehavior: () => false` — scroll is managed by `useScrollRestore`, not the router.

### Sections

All sections share a common structure: `id` attribute for anchor navigation, `py-24 px-4` padding, `max-w-5xl`/`max-w-6xl` container, and `UiScrollReveal` wrappers for entrance animations.

- **HeroSection** — Greeting, name, title, subtitle, tagline with staggered `hero-fade` CSS animations (fadeInUp with `--delay` custom property). Two CTAs: contact (smooth-scrolls) and resume download (fetches PDF as blob, triggers download). Scroll indicator at bottom with bouncing dot animation.
- **AboutSection** — Bio card with profile image, text, and stats grid (StatCard components for languages, projects, internship months).
- **SkillsSection** — Filterable skill grid with smart column distribution algorithm (`distribute()` balances column heights). Responsive: 1 column mobile (ordered by 3-col layout), 2 columns tablet, 3 columns desktop.
- **ExperienceSection** — Timeline layout with `TimelineItem` cards. Items loaded dynamically from i18n via `te()` existence checks (up to 99 items).
- **ProjectsSection** — Filterable project grid (tabs: all/epitech/personal/hackathon/jam) grouped by year. Uses `useProjectsData()` for data.
- **ContactSection** — Three contact links; email obfuscated via base64, decoded on mount.
- **FooterSection** — Copyright year + credits with i18n.

### HeroBackground

Fixed fullscreen background (z-index 0) with:
- 4 animated gradient orbs (radial gradients with blur, responsive sizes from 200–700px)
- Grid overlay (opacity 0.1, theme-responsive line color via computed property)
- 12 floating geometric shapes (squares, circles, borders) with orange color, 6 hidden on mobile
- CSS `float` / `float-slow` keyframe animations

### Navbar

- `nav::before` pseudo-element handles gradient background + `backdrop-filter: blur(24px)` with opacity transition
- `@property` registered `--nav-bg-top` and `--nav-bg-bottom` as `<color>` to enable smooth theme transitions on gradient
- Navbar shadow uses `--shadow-color` theme variable via `.nav-scrolled` CSS class
- Desktop links are screen-centered (absolute positioning, falls back to flex on narrow viewports)
- Active section detection uses 40% viewport checkpoint algorithm
- Transition timings: 300ms for normal scroll show/hide, 200ms for menu close (matching `panel-out` animation)
- Mobile menu uses CSS `@keyframes` animations (not Vue transitions) with `animationend` listener to manage `mobileVisible`/`mobileOpen` state
- Inverted concave corners on mobile menu use `radial-gradient` on sibling divs with `--corner-border` (opaque color from `color-mix`)

### UI Components

- **GlassCard** — Frosted glass effect with optional hover animation. Wraps content with `UiGlowingEffect` (lazy-loaded on window load to avoid flash).
- **GlowingEffect** — Orange radial gradient glow following cursor. Uses a single pair of global `pointermove`/`scroll` listeners at module level; individual instances register callbacks in a shared `Set`. The glow uses a radial gradient mask positioned at the nearest border point. Animates via `motion` library.
- **OrangeButton** — Polymorphic button/link component with `variant` (solid/outline), `href`, `download` props.
- **ScrollReveal** — IntersectionObserver-based entrance animation wrapper with `delay` prop. Uses `useScrollReveal()` composable.
- **SectionTitle** — Centered h2 with orange underline bar.
- **TechTag** — Inline pill badge for technology tags.
- **ThemeToggle / LanguageToggle** — Both use CSS grid `0fr → 1fr` trick to animate text show/hide without hardcoded widths. On desktop text is always visible (`md:!grid-cols-[1fr]`), on mobile it toggles with `showText` prop from the navbar menu state.

### Composables

- `useTheme` — Module-level `theme` ref (`dark`/`light`). `applyTheme()` swaps class on `<html>`. `toggleTheme()` persists to localStorage. Deferred init via `onNuxtReady()`.
- `useScrollRestore` — Module-level `isRestoring` ref shared across consumers. Saves scroll position to sessionStorage (RAF-throttled), restores on mount with retry loop (up to 10 frames). Disables browser native scroll restoration.
- `useScrollReveal` — IntersectionObserver-based entrance animation. Returns `{ target, isVisible, skipAnimation }`. Integrates with scroll restore to instantly reveal elements already above viewport.
- `useSmoothScroll` — `scrollToSection(sectionId)` calls `scrollIntoView({ behavior: 'smooth', block: 'start' })`.
- `useProjectsData` — Returns typed `Project[]` with `key, techTags, type, year, current?, github?, liveUrl?`. ~20 projects from 2024–2026.
- `useExperienceData` — Returns typed `ExperienceEntry[]` with `key, current?`. 3 entries (Epitech, 2 Naitways internships).
- `useSkillsData` — Returns typed `SkillCategory[]` with `key, skills: { name, icon, mono? }[]`. 8 categories using Iconify devicon/mdi icon sets.

### Tailwind

Custom colors in `tailwind.config.ts` use CSS custom properties with `rgb(var(...) / <alpha-value>)` pattern to support opacity modifiers. All theme colors (orange-accent, glass, dark-bg, text-primary, etc.) are defined this way. Font: Inter (weights 300–700, self-hosted woff2 with latin + latin-ext unicode ranges).

### Key files

- `app/app.vue` — Root component: template, theme CSS variables, global transitions, scroll restore integration
- `nuxt.config.ts` — Nuxt config, Nitro hooks for redirect pages, pre-hydration inline script, meta/SEO tags
- `tailwind.config.ts` — Custom theme colors, font config
- `app/router.options.ts` — Disables router scroll behavior
- `locales/en.json`, `locales/fr.json` — All UI text (nav, hero, about, skills, experience, projects, contact, footer)
- `app/assets/css/animations.css` — Scroll-reveal keyframes, float animations, scroll indicator
- `app/assets/css/fonts.css` — Self-hosted Inter font-face declarations

### Vite

`motion` is listed in `vite.optimizeDeps.include` to ensure proper pre-bundling for the GlowingEffect component.
